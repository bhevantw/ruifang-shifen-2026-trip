## 行程假設

- 日期：2026-09-26（星期六）。
- 出發點：南勢角捷運站；08:25 集合、08:30 準時出發。17:30 左右回到南勢角是順利時的好方向，不是硬性的返家限制。
- 主班次：臺北 09:20 → 瑞芳 10:28；瑞芳 11:55 → 十分 12:22；十分 14:40 → 瑞芳 15:12；瑞芳 16:09 → 臺北 17:02。
- 回到瑞芳後建議 15:20 先前往新村芳書院，再到瑞芳街 8 號的保雲芋圓；書院目前沒有可信的固定開放時間，因此以巷弄與老屋外觀為保底，現場開放才入內。16:09 回臺北是順利時的首選；想多留可搭後續班次，接受返家可能晚於 19:00 即可。
- 14:40 十分回瑞芳是能完整安排瑞芳後站收尾的首選班次；錯過時仍可選晚班，不把 19:00 前到家視為硬性要求。
- 網頁另列臺北／瑞芳／十分各段可替換班次，並說明較晚回程的取捨。
- 頁面最上方先有整日行程摘要，讓閱讀者先掌握交通與停留架構；其後是瑞芳美食廣場導覽，依食記與網友回饋介紹佳佳肉羹油飯、李記蚵仔煎、林記福州胡椒餅，並標示胡椒餅可能等候的行程風險。詳細內容再以新村芳書院、保雲芋圓、十分鐵道老街、河谷步道與十分瀑布為主軸；每個主要行程都搭配實景照片，詳細時間表、備用班次及臨時調整資訊放在景點介紹之後。
- 列車、天氣與景點開放狀況都可能臨時變動，出發前應重新檢查。
