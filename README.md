- 日期：2026-09-26（星期六）。
- 出發點：南勢角捷運站；08:25 集合、08:30 準時出發，目標 17:30 左右回到南勢角，保留約 30 分鐘回家。
- 主班次：臺北 09:20 → 瑞芳 10:28；瑞芳 11:55 → 十分 12:22；十分 14:40 → 瑞芳 15:12；瑞芳 16:09 → 臺北 17:02。
